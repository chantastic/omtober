Omarchy as my daily driver.

I'm Michael Chan (chantastic). This October I'm using Omarchy as the operating system I actually work on every day, and writing down what happens.

What's this?

Omarchy is DHH's opinionated Linux setup: Arch Linux with the Hyprland tiling window manager, preconfigured from top to bottom. It's built around the keyboard rather than the mouse.

omtober = Omarchy + October. Daily driver means real work, not a weekend VM. The log is where I write down what works, what breaks, and what changes about how I work.
